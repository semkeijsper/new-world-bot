# New World Bot

A Discord bot that automatically looks up Bible verses when you mention them in chat.

### **[Add to your server](https://discord.com/oauth2/authorize?client_id=1280592282541625466)**

## How it works

Just mention a Bible verse in any message — the bot will fetch and post it automatically. No commands needed.

**Supported formats:**

| You type | What it fetches |
|---|---|
| `Genesis 1:1` | Genesis 1, verse 1 |
| `Gen 1:1-5` | Genesis 1, verses 1–5 |
| `Ge 1:1-2:5` | Genesis 1:1 through Genesis 2:5 |
| `Gen 1:1, 3-5` | Genesis 1 verses 1, 3, 4 and 5 |
| `1 John 2:1` | 1 John 2, verse 1 |

Multiple verses in one message all get fetched in a single response. All 66 books of the Bible are supported, and most common abbreviations work (e.g. `Gen`, `Genesis`, `Ge`).

Verses are sourced from [wol.jw.org](https://wol.jw.org).
